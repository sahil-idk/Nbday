Add your background images or animated GIFs to this folder with the following names:

- `hero.gif` - 🎬 **ANIMATED GIF** for the hero/landing section (blue themed, animated)
- `arcane.gif` - 🎬 **CAN BE GIF** for the Arcane mood section (dark mystic, animated)
- `brooklyn99.gif` - 🎬 **CAN BE GIF** for Brooklyn 99 quiz section (fun, vibrant, animated)

## Image/GIF Specs:

### For Static Images (JPG/PNG/WebP):
- **Format**: JPG, PNG, or WebP
- **Size**: 1920x1080px minimum (Full HD)
- **Orientation**: Landscape
- **File Size**: Keep under 500KB each for best performance
- **Style**: Blue tones preferred, matching the overall theme

### For Animated GIFs:
- **Format**: GIF
- **Size**: 1920x1080px recommended (can be smaller, will scale)
- **Orientation**: Landscape
- **File Size**: 1-3MB max (GIFs are larger, but smooth animations are worth it!)
- **Frame Rate**: 15-30 fps
- **Style**: Blue tones, smooth loops, subtle animations work best
- **Note**: Hero section GIF appears behind "For Namrata — a little blue for your birthday" text

## Tips:
1. **Blur effect**: Consider using slightly blurred or soft-focus images for a dreamy effect
2. **Compression**:
   - Images: Use [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/)
   - GIFs: Use [Ezgif](https://ezgif.com/optimize) to optimize and reduce file size
3. **Consistency**: Keep a consistent color tone (blue shades) across all backgrounds
4. **Contrast**: Ensure text readability - darker backgrounds work better
5. **Gradients**: The system adds lighter blue gradients on top of GIFs (to show animation better)
6. **GIF Loops**: Make sure your GIFs loop seamlessly for continuous animation
7. **Smooth Animations**: Subtle, slow animations work better than fast, jerky ones

## Fallback:
If images are not added, the system will display blue gradient backgrounds by default.
