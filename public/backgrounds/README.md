# Background Images

Add your background images to this folder with the following names:

## Required Images:
- `hero.jpg` - For the hero/landing section (blue themed)
- `arcane.jpg` - For the Arcane mood section (dark mystic theme)
- `brooklyn99.jpg` - For Brooklyn 99 quiz section (fun, vibrant)
- `gallery.jpg` - For the memory gallery section
- `journey.jpg` - For the interactive journey map section
- `shayari.jpg` - For the shayari/poetry section (elegant, calm)
- `playlist.jpg` - For the playlist section (music themed)
- `date.jpg` - For the date planner section (romantic)
- `footer.jpg` - For the footer section (dark, closing mood)

## Image Specs:
- **Format**: JPG, PNG, or WebP
- **Size**: 1920x1080px minimum (Full HD)
- **Orientation**: Landscape
- **File Size**: Keep under 500KB each for best performance
- **Style**: Blue tones preferred, matching the overall theme

## Tips:
1. **Blur effect**: Consider using slightly blurred or soft-focus images for a dreamy effect
2. **Compression**: Use [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/) to optimize
3. **Consistency**: Keep a consistent color tone (blue shades) across all images
4. **Contrast**: Ensure text readability - darker images work better
5. **Gradients**: The system adds blue gradients on top, so lighter base images work well

## Fallback:
If images are not added, the system will display blue gradient backgrounds by default.

## Example Sources:
- [Unsplash](https://unsplash.com/) - Free high-quality photos
- [Pexels](https://pexels.com/) - Free stock photos
- Personal photos with blue filters applied
- AI-generated backgrounds (Midjourney, DALL-E)

## Smooth Transitions:
The background images will smoothly crossfade as users scroll through sections. No visible borders or jumps between images!
