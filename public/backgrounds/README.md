## GIF Specifications:
- **Format**: GIF (animated)
- **Size**: 1920x1080px recommended (Full HD) - can be smaller, will scale
- **Orientation**: Landscape
- **File Size**: 1-3MB max (optimize for web!)
- **Frame Rate**: 15-30 fps
- **Loop**: Seamless loops (no jarring cuts)
- **Color Themes**:
  - Sections 1-7: **Blue tones** (hero through playlist)
  - Section 8: **Blue to reddish transition** (date section)
  - Section 9: **Reddish/pink tones** (footer - VI theme!)
- **Note**: All GIFs appear behind section content with semi-transparent gradient overlays

## Tips for Best Results:
1. **Seamless Loops**: Make sure your GIFs loop perfectly with no visible restart
2. **Optimization**: Use [Ezgif](https://ezgif.com/optimize) to compress GIFs (1-3MB target)
3. **Color Consistency**:
   - Sections 1-7: Blue tones (#1e3a8a, #3b82f6, #60a5fa)
   - Date section: Blue → Reddish transition
   - Footer: VI's signature pink/red (#be185d, #8b285c)
4. **Smooth Animations**: Slow, subtle movements work better than fast, jerky ones
5. **Contrast**: Darker GIFs ensure text remains readable
6. **Blur Effect**: Slightly blurred GIFs create a dreamy, professional look
7. **Gradient Overlays**: System adds semi-transparent overlays to enhance readability

## Fallback:
If images are not added, the system will display blue gradient backgrounds by default.
